What Is the Enye Letter?

The Enye is the letter Ñ in uppercase and ñ in lowercase. It is a distinct letter used prominently in Spanish and also appears in Filipino writing, names and place names.

If you are writing Spanish, using the correct letter matters. For example, año, niño and mañana contain ñ and should not normally be written with a plain n.

Because many English keyboard layouts do not have Ñ as a dedicated key, people commonly search for ways to type enye, copy enye, find an enye keyboard shortcut, or enter the character using an Alt code.

How to Type Ñ on Windows

If you are using a Windows desktop keyboard with a dedicated numeric keypad, the traditional Alt-code method is one of the quickest ways to enter Ñ or ñ.

Character Windows Alt Code Unicode
ñ Alt + 164 U+00F1
Ñ Alt + 165 U+00D1

Type lowercase ñ on Windows

  1. Make sure Num Lock is enabled.
  2. Place the cursor where you want the letter.
  3. Hold down the Alt key.
  4. Type 164 using the numeric keypad.
  5. Release Alt.

The result should be ñ.

Type uppercase Ñ on Windows

  1. Make sure Num Lock is enabled.
  2. Place the cursor in the text field.
  3. Hold down Alt.
  4. Type 165 using the numeric keypad.
  5. Release Alt.

The result should be Ñ.

Important: Traditional Windows Alt-code entry normally requires the numeric keypad. Typing 164 or 165 on the number row above the letters may not produce the same result.

How to Type Ñ on a Windows Laptop Without Numpad

Compact laptops often do not include a dedicated numeric keypad. This makes the traditional Alt-code method inconvenient or unavailable depending on the keyboard.

If you only need Ñ occasionally, copying the character is usually the fastest solution.

Windows also includes character and symbol tools that can help when you regularly need special characters.

How to Type Ñ on Mac

macOS provides a simple keyboard shortcut for accented characters.

Lowercase ñ

  1. Press Option + N.
  2. Release both keys.
  3. Press N.

The result is ñ.

Uppercase Ñ

  1. Press Option + N.
  2. Release both keys.
  3. Press Shift + N.

The result is Ñ.

How to Type Ñ on iPhone and iPad

On the standard iPhone or iPad keyboard, you generally do not need a separate shortcut.

  1. Open an app where you can type.
  2. Tap the text field.
  3. Press and hold the N key.
  4. Wait for the accented-character choices to appear.
  5. Move your finger to ñ or Ñ.
  6. Release your finger.

The available characters can vary according to the keyboard and language settings installed on the device.

How to Type Ñ on Android

Many Android keyboards provide accented characters through a long-press gesture.

  1. Open a text field to display the keyboard.
  2. Press and hold N or n.
  3. Wait for the alternate characters to appear.
  4. Select Ñ or ñ.
  5. Release your finger.

If your keyboard does not show Ñ, you can copy the character instead.

How to Type Ñ in Microsoft Word

Microsoft Word accepts Ñ and ñ as normal Unicode characters. On Windows, you can use the numeric-keypad Alt codes directly inside a Word document.

Lowercase ñ → Alt + 164
Uppercase Ñ → Alt + 165

You can also use Word's symbol tools if you prefer selecting the character from a menu instead of using a keyboard shortcut.

How to Type Ñ in Google Docs

Google Docs supports Ñ and ñ as Unicode text. You can therefore use your operating system's keyboard method or copy the character and paste it into your document.

Simple method: Copy Ñ or ñ → open Google Docs → place your cursor → paste.

How to Type Ñ With a Spanish Keyboard

If you frequently write Spanish, changing your keyboard layout to a Spanish keyboard can make accented characters much easier to enter. The exact key arrangement depends on whether you use a Spanish, Latin American or another keyboard layout.

For occasional use, switching keyboard layouts may be unnecessary. A direct copy method or the keyboard shortcut available on your device can be faster.

Ñ and ñ Unicode Codes

Unicode assigns a unique code point to each character so that modern computers, browsers and applications can represent the character consistently.

Character Unicode HTML Entity
Ñ U+00D1 &Ntilde;
ñ U+00F1 &ntilde;

If you are working with HTML, the entities &Ntilde; and &ntilde; can be used to represent the two characters in HTML source.

Common Spanish Words That Use Ñ

The letter appears in many everyday Spanish words. Here are some examples:

  • niño — boy / child
  • niña — girl
  • mañana — tomorrow / morning
  • año — year
  • España — Spain
  • señor — Mr. / sir
  • baño — bathroom
  • piña — pineapple
  • pequeño — small / little
  • montaña — mountain

Replacing Ñ with N can produce an incorrect spelling, so using the proper character is important when writing Spanish names, words and sentences.

Why Can't I Type Ñ With Alt + 165?

If Alt + 165 does not work, the most common issue is that the numbers are being entered from the number row instead of a dedicated numeric keypad.

Other possible causes include Num Lock being disabled, a different keyboard configuration, or the application handling keyboard input differently.

Quick troubleshooting

  • Check that Num Lock is enabled.
  • Use the numeric keypad rather than the number row.
  • Try the shortcut inside a normal text editor.
  • Check your Windows keyboard layout.
  • If you only need the character once, copy Ñ or ñ instead.

Frequently Asked Questions

How do I type Ñ on a Windows keyboard?

With a Windows keyboard that has a numeric keypad, turn on Num Lock, hold Alt and type 165 for uppercase Ñ or 164 for lowercase ñ.

How do I type Ñ on a laptop without a number pad?

Traditional Windows Alt codes are inconvenient without a dedicated numeric keypad. You can use Windows character tools or copy Ñ and ñ directly.

How do I type ñ on a Mac?

Press Option + N, release the keys, and then press N. For uppercase Ñ, use Shift + N for the final letter.

How do I type Ñ on an iPhone?

Press and hold the N key on the iPhone keyboard, then select Ñ or ñ from the accented-character choices.

How do I type Ñ on Android?

On many Android keyboards, press and hold N or n and select Ñ or ñ from the alternate characters.

What is the Unicode for Ñ?

Uppercase Ñ is U+00D1 and lowercase ñ is U+00F1.

Can I copy Ñ and paste it into Word or Google Docs?

Yes. Ñ and ñ are Unicode characters and can normally be copied and pasted into Word, Google Docs, email, websites and other modern applications.

Is Ñ the same as N?

No. Ñ is a distinct letter. In Spanish, it is part of the spelling of many words and names, so replacing it with a plain N can change the spelling.
