What Is the Enye Letter?

The Enye is the letter Ñ in uppercase and ñ in lowercase. It is used prominently in Spanish and also appears in Filipino writing, names and place names.

Because Ñ is not present as a normal key on many English keyboards, users often search for ways to type enye, copy enye, or find the Ñ keyboard shortcut. The correct method depends on your device and keyboard layout.

How to Type Ñ on Windows

If you have a Windows desktop keyboard with a dedicated numeric keypad, the Alt code is one of the quickest methods.

Character Windows Alt Code Unicode
ñ Alt + 164 U+00F1
Ñ Alt + 165 U+00D1

Type lowercase ñ

  1. Turn on Num Lock.
  2. Place the cursor where you want the letter.
  3. Hold the Alt key.
  4. Type 164 using the numeric keypad.
  5. Release Alt. The result should be ñ.

Type uppercase Ñ

  1. Make sure Num Lock is enabled.
  2. Hold Alt.
  3. Type 165 on the numeric keypad.
  4. Release Alt to insert Ñ.
Important: Traditional Windows Alt codes generally require the numeric keypad. The number row above the letters may not produce the same result.

If you are using a laptop without a numeric keypad, see our dedicated guide: How to Type Ñ Without a Numpad.

How to Type Ñ on Mac

macOS makes accented characters easy to enter from the keyboard.

Lowercase ñ

  1. Press Option + N.
  2. Release both keys.
  3. Press N.
  4. The result is ñ.

Uppercase Ñ

  1. Press Option + N.
  2. Release both keys.
  3. Press Shift + N.
  4. The result is Ñ.

This method works without a separate number pad.

How to Type Ñ on iPhone and iPad

On the standard iOS keyboard, you normally do not need a special shortcut.

  1. Open any app where you can type.
  2. Tap the text field.
  3. Press and hold the N key.
  4. When the accented-character menu appears, slide to ñ or Ñ.
  5. Release your finger to insert the character.

The exact keyboard appearance can vary depending on the installed keyboard and language settings.

How to Type Ñ on Android

Most common Android keyboards support accented characters through a long press.

  1. Open a text field to display your keyboard.
  2. Press and hold N or n.
  3. Wait for the alternate characters to appear.
  4. Move your finger to ñ or Ñ.
  5. Release to insert it.

How to Type Ñ in Microsoft Word

You can use the same operating-system keyboard methods inside Microsoft Word. On Windows, the numeric-keypad Alt codes are particularly convenient.

Lowercase: Alt + 164 → ñ
Uppercase: Alt + 165 → Ñ

You can also insert the character through Word's symbol tools when you need to find it manually.

How to Type Ñ in Google Docs

Google Docs accepts Ñ and ñ like normal Unicode text. You can therefore use your operating system's keyboard shortcut or simply copy the character from this page.

For occasional use, the fastest method is usually: copy Ñ or ñ → place the cursor in Google Docs → paste.

Common Spanish Words That Use Ñ

Seeing the letter in real words can also make it easier to recognize when you need it while typing Spanish.

  • niño — boy / child
  • niña — girl
  • mañana — tomorrow / morning
  • año — year
  • España — Spain
  • señor — Mr. / sir
  • baño — bathroom
  • piña — pineapple
  • pequeño — small / little
  • montaña — mountain

Because replacing Ñ with N can change the spelling and sometimes the meaning of a word, using the correct character matters when writing Spanish.

Why Can't I Type Ñ With Alt + 165?

The most common reason is that you are using the number row instead of a numeric keypad. Traditional Windows Alt-code entry is designed around the numeric keypad.

Other possibilities include Num Lock being disabled, a different keyboard configuration, or the application handling keyboard input differently.

Frequently Asked Questions

How do I type Ñ on a Windows keyboard?

Use Alt + 165 for uppercase Ñ or Alt + 164 for lowercase ñ with a numeric keypad. If your keyboard has no Numpad, use a character tool or copy the letter directly.

How do I type Ñ on a laptop without a number pad?

A laptop without a dedicated numeric keypad may not support the traditional Alt-code method conveniently. You can use Windows character tools or copy Ñ and ñ from the Enye CopyPaste tool.

How do I type ñ on a Mac?

Press Option + N, release the keys, and press N again. For uppercase Ñ, use Shift + N for the final letter.

How do I type Ñ on an iPhone?

Open the iPhone keyboard, press and hold N, then select Ñ or ñ from the accented-character choices.

How do I type Ñ on Android?

Press and hold N or n on the Android keyboard and select the Ñ or ñ option when it appears.

What is the Unicode for Ñ?

Uppercase Ñ is U+00D1. Lowercase ñ is U+00F1.

Can I copy Ñ and paste it into Word or Google Docs?

Yes. Ñ and ñ are Unicode characters and can normally be copied and pasted into Word, Google Docs, email, social media and other modern applications.
