How to Type Ñ or ñ on Windows 10 & 11

Need to type the Spanish letter Ñ or ñ on a Windows 10 or Windows 11 PC? You can use a simple Alt code if your keyboard has a numeric keypad. If you're using a laptop without one, there are other practical ways to enter the character.

Quick answer:
  • Lowercase ñ: Hold Alt and type 164 on the numeric keypad.
  • Uppercase Ñ: Hold Alt and type 165 on the numeric keypad.
  • Alternative codes: Alt + 0241 for ñ and Alt + 0209 for Ñ.
  • No numeric keypad? Use Windows character tools, an on-screen keyboard, or copy the character directly.

1. Type ñ and Ñ With Windows Alt Codes

The classic Windows method is the Alt code. It is especially useful when you regularly type Spanish words containing the Enye letter.

Character Alt Code Result
Lowercase enye Alt + 164 ñ
Lowercase enye Alt + 0241 ñ
Uppercase enye Alt + 165 Ñ
Uppercase enye Alt + 0209 Ñ

How to use the Alt code

  1. Open the document, browser field, or application where you want to type Ñ.
  2. Make sure Num Lock is enabled.
  3. Place the cursor where the letter should appear.
  4. Hold the Alt key.
  5. Type the required numbers using the numeric keypad.
  6. Release Alt and the character should appear.
Important: Traditional Windows Alt codes generally require the numeric keypad. Typing the numbers from the number row above the letters may not produce the same result.

2. How to Type Uppercase Ñ

If you specifically need the capital Enye, Ñ, the simplest Windows Alt code is:

Hold Alt → type 165 → release Alt → Ñ

You can also use Alt + 0209 on systems where the four-digit code works.

This is useful for names, headings and Spanish words that require an uppercase first letter.

3. How to Type Lowercase ñ

For the lowercase character, ñ, use:

Hold Alt → type 164 → release Alt → ñ

The alternative four-digit code is Alt + 0241.

For example, you can use the character in words such as niño, mañana, año, and España.

4. What If Your Laptop Has No Numeric Keypad?

This is where many laptop users get stuck. Compact Windows laptops often do not include a separate numeric keypad, so the traditional Alt-code method may not be convenient.

You have several alternatives.

Use Windows character tools

Windows provides built-in ways to insert special characters without relying entirely on a physical numeric keypad. Depending on your Windows version and keyboard configuration, you can use the available character or emoji/symbol interface to locate Ñ and ñ.

Use an on-screen keyboard

Windows also includes an on-screen keyboard. If your physical keyboard does not provide a convenient numeric keypad, the on-screen keyboard can give you another way to access characters and keyboard controls.

Use copy and paste

If you only need Ñ or ñ occasionally, copying the character is often faster than changing keyboard settings or searching through character menus.

5. How to Type Ñ in Microsoft Word

Microsoft Word supports the same Windows keyboard methods, so an Alt code with a numeric keypad can be one of the quickest options.

For example:

  • Alt + 164 → ñ
  • Alt + 165 → Ñ

If you do not have a numeric keypad, Word also provides symbol insertion options. You can open the symbol interface, find the required character and insert it into your document.

For occasional use, copying the character and pasting it into Word is usually the quickest solution.

6. How to Type Ñ in Google Docs

Google Docs works well with copied Unicode characters, so you can paste Ñ or ñ directly into your document.

If your Windows keyboard configuration supports the required Alt code, you can also enter the character directly while working in Google Docs.

For users who frequently write Spanish text, setting up an appropriate keyboard layout can be more convenient than repeatedly using character insertion tools.

7. Windows Keyboard Layout Is Another Option

If you frequently type Spanish rather than needing Ñ only once or twice, consider adding a Spanish keyboard layout in Windows.

A dedicated Spanish layout can make Spanish punctuation and characters easier to access while writing longer passages.

However, changing keyboard layouts is not necessary if your only goal is to type Ñ occasionally. For occasional use, an Alt code or copy-and-paste method is usually simpler.

8. Common Problems With the Ñ Alt Code

Alt + 164 does nothing

Check whether Num Lock is enabled and whether you are using the numeric keypad rather than the number row above the letters.

The laptop has no number pad

Try Windows' built-in character tools or an on-screen keyboard. You can also copy Ñ or ñ directly when you only need the character occasionally.

The wrong character appears

Windows keyboard layouts and application behavior can differ. Try the alternative four-digit code or use a Unicode-aware insertion method.

I need Ñ many times while writing

For frequent Spanish writing, adding a Spanish keyboard layout may be more practical than repeatedly using Alt codes.

9. Ñ and ñ Unicode Values

The Enye characters are Unicode characters, which is why they can be copied and used across modern websites, documents and applications.

Character Unicode HTML Entity
ñ U+00F1 &ntilde;
Ñ U+00D1 &Ntilde;

This is also why simply copying the actual character is different from copying text such as “Alt + 164”. The first is the character itself; the second is only the keyboard instruction.

11. Which Method Should You Use?

If you have a Windows keyboard with a numeric keypad and only need Ñ occasionally, Alt + 165 and Alt + 164 are straightforward choices.

If you're using a laptop without a numeric keypad, Windows character tools or copy and paste are usually easier.

If you write Spanish frequently, adding a Spanish keyboard layout can provide a more natural long-term workflow.

And if you simply need the letter right now, there is no reason to spend time changing settings: copy the character and continue writing.
