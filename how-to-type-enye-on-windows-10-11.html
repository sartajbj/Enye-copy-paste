How to Type Enye (Ñ or ñ) on Windows 10 & 11: 5 Easy Ways

Published on July 14, 2026 • 5 Min Read

If you need to type the Spanish letter Enye (Ñ or ñ) on a Windows 10 or Windows 11 PC, you do not need to install a special program. Windows already provides several ways to enter the character, whether you have a full-size keyboard, a laptop, or a touchscreen device.

The best method depends on your keyboard. A desktop keyboard with a numeric keypad can use Alt codes, while a laptop without a numpad may be easier with the Windows symbol tools, Character Map, or another keyboard layout.

Quick Answer: Type Ñ or ñ on Windows

Capital Ñ: Alt + 165 using a numeric keypad.

Small ñ: Alt + 164 using a numeric keypad.

If your keyboard has no numpad, use the Windows Symbols panel, Character Map, or the touch keyboard instead.

1. Use Alt Codes on a Windows Keyboard

The familiar Windows Alt-code method is one of the quickest options when your keyboard has a dedicated numeric keypad. It does not use the number row above the letters; the numbers need to be entered through the numeric keypad.

For Capital Ñ

Turn on Num Lock, hold Alt, type 165 on the numeric keypad, and then release Alt.

For Small ñ

Hold Alt, type 164 on the numeric keypad, and release Alt.

Important: These Alt-code instructions are mainly useful on keyboards with a numeric keypad. If you are using a compact laptop without one, use one of the methods below.

2. Use the Windows Symbols Panel

Windows also includes a built-in symbols panel that is useful when you only need Enye occasionally. This is a convenient option because you do not have to remember an Alt code or change your keyboard layout.

  1. Click inside the document, search box, message, or other place where you want to type.
  2. Press Windows + . (period).
  3. Open the Symbols section.
  4. Browse the available Latin characters and select Ñ or ñ.

This method is especially useful on laptops where the traditional numeric-keypad Alt codes are inconvenient.

3. Use Character Map

Character Map is another Windows utility that lets you find special characters and copy them into another application. It can be useful when you want to see the character before inserting it.

  1. Press Windows + R.
  2. Type charmap and press Enter.
  3. Find Ñ or ñ in the character grid.
  4. Select the character and choose Copy.
  5. Paste it into Word, a browser, an email, or another application.

Character Map is a good fallback when you do not remember a shortcut and want a built-in Windows solution rather than an additional app.

4. Use a Windows Keyboard Layout

If you regularly type Spanish words containing accented characters, changing or adding a suitable keyboard layout can be more convenient than repeatedly using character tools.

  1. Open Settings.
  2. Go to Time & Language and then Language & Region.
  3. Open the language options for your installed language.
  4. Add an appropriate keyboard layout.
  5. Switch between installed layouts from the Windows language indicator when needed.

Keyboard-layout shortcuts can vary depending on the exact layout you select. Once the Spanish or another suitable layout is active, Enye can be entered using the character position provided by that layout.

5. Use the Windows Touch Keyboard

Windows touchscreen devices provide another simple option. The touch keyboard can display alternate characters when you press and hold a letter.

  1. Enable the touch keyboard button from the Windows taskbar settings.
  2. Open the touch keyboard.
  3. Press and hold the N or n key.
  4. If alternate characters are available, select Ñ or ñ.

This is particularly convenient on a 2-in-1 laptop or touchscreen Windows device where using a physical keyboard is not always practical.

Which Windows Method Should You Use?

For a full-size keyboard with a numeric keypad, Alt + 164 and Alt + 165 are convenient because they are quick to remember. On a compact laptop, the Symbols panel or Character Map is usually easier. If you type Spanish characters regularly, setting up a suitable keyboard layout can save time in the long run.

The important thing is to choose the method that matches your hardware. There is no reason to install extra software just to type one character when Windows already includes several options.
