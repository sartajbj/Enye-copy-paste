How to Type Ñ or ñ on Windows 10 & 11

This Windows-focused guide explains which input methods work in which situations: legacy Alt codes with a numeric keypad, the built-in Character Map, Word's Unicode conversion, and a Spanish keyboard layout for regular typing. The steps are different from simply pressing the number row above the letters.

Quick answer:
  • With a numeric keypad: try Alt + 164 for ñ or Alt + 165 for Ñ.
  • In Microsoft Word: type 00F1, then press Alt + X for ñ; use 00D1 + Alt + X for Ñ.
  • In Windows generally: open Character Map by running charmap, select the character, and copy it.
  • For frequent Spanish typing: add a Spanish keyboard layout and switch to it with Windows + Space.

1. Use a Windows Alt Code With a Numeric Keypad

The traditional Alt-code method is useful on a full-size keyboard or a laptop with a working numeric keypad. It is not a universal shortcut: the result can depend on the code, Windows input context, and application. Use the keypad digits, not the number row above the letters.

How to use the Alt code

  1. Open the document, browser field, or application where you want to type Ñ.
  2. Make sure Num Lock is enabled.
  3. Place the cursor where the letter should appear.
  4. Hold the Alt key.
  5. Type the required numbers using the numeric keypad.
  6. Release Alt and the character should appear.
Important: Traditional Windows Alt codes generally require the numeric keypad. Typing the numbers from the number row above the letters may not produce the same result.

2. Enter Uppercase Ñ and Lowercase ñ

For Ñ, hold Alt, enter 165 on the numeric keypad, then release Alt. For ñ, use Alt + 164. Some Windows applications and legacy code-page contexts also accept the zero-prefixed forms Alt + 0209 and Alt + 0241, but do not assume every application handles both forms identically.

If the character does not appear, check Num Lock, make sure you are using the numeric keypad, and test the method in a plain-text editor. If your keyboard has no numeric keypad, skip these codes and use one of the methods below.

Examples of words that use lowercase ñ include niño, mañana, año, and España.

3. Use Character Map When You Do Not Have a Numeric Keypad

Character Map is included with Windows 10 and Windows 11. It lets you locate a character visually and copy it without entering an Alt code or changing the physical keyboard.

  1. Press Windows + R to open Run.
  2. Enter charmap and press Enter.
  3. In Character Map, find Ñ or ñ. If needed, enable the advanced view and search for the character by name or Unicode value.
  4. Select the character, choose Select if that button is shown, then choose Copy.
  5. Return to your document or text field and paste it.

Character Map is a practical fallback when an application does not accept an Alt code. It also avoids changing your active keyboard layout.

Do not confuse the on-screen keyboard with a numeric keypad

Windows On-Screen Keyboard displays a virtual version of a keyboard, but it does not guarantee that every device or application will treat its keys as a physical numeric keypad for Alt-code entry. Use Character Map if you need a dependable no-numpad route.

4. Use Word's Unicode Shortcut

Microsoft Word for Windows can convert a Unicode hexadecimal value into its character with Alt + X. This is useful when you do not have a numeric keypad.

00F1Alt + Xñ
00D1Alt + XÑ

Place the cursor after the four-character code before pressing Alt + X. If the letters are part of a longer string of hexadecimal characters, select the code first so Word converts the intended characters. This shortcut is a Microsoft Word feature; it is not a general Windows shortcut for every app.

You can also open Insert > Symbol, choose the character, and insert it directly.

5. Insert Ñ in Google Docs

Google Docs works well with copied Unicode characters, so you can paste Ñ or ñ directly into your document.

If your Windows keyboard configuration supports the required Alt code, you can also enter the character directly while working in Google Docs.

For users who frequently write Spanish text, setting up an appropriate keyboard layout can be more convenient than repeatedly using character insertion tools.

6. Add a Spanish Keyboard Layout for Frequent Typing

If you regularly write Spanish, a Spanish keyboard layout is more convenient than entering a code each time. You can add one without replacing your physical keyboard.

  1. Open Settings with Windows + I.
  2. In Windows 11, go to Time & language > Language & region. In Windows 10, go to Time & Language > Language.
  3. Add Spanish as a language or open the language options for an installed Spanish language.
  4. Under keyboard options, add the Spanish layout you want.
  5. Switch between installed layouts with Windows + Space.

The key position for Ñ depends on the layout you selected. The labels printed on your physical keyboard may no longer match the active layout, so check the on-screen layout before typing if you are unfamiliar with it. You can switch back with Windows + Space.

7. Troubleshoot Common Windows Input Problems

Alt + 164 does nothing

Check whether Num Lock is enabled and whether you are using the numeric keypad rather than the number row above the letters.

The laptop has no number pad

Try Windows' built-in character tools or an on-screen keyboard. You can also copy Ñ or ñ directly when you only need the character occasionally.

The wrong character appears

Windows keyboard layouts and application behavior can differ. Try the alternative four-digit code or use a Unicode-aware insertion method.

I need Ñ many times while writing

For frequent Spanish writing, adding a Spanish keyboard layout may be more practical than repeatedly using Alt codes.

8. Unicode Values for Ñ and ñ

The Enye characters are Unicode characters, which is why they can be copied and used across modern websites, documents and applications.

This is also why simply copying the actual character is different from copying text such as “Alt + 164”. The first is the character itself; the second is only the keyboard instruction.

10. Quick Recommendation

Use Alt codes when you have a numeric keypad and the target application accepts them. Use Character Map when you need a Windows-wide visual picker, Word's Alt + X conversion when you are already writing in Word, and a Spanish layout when you type Spanish regularly.

If you only need one character, copying Ñ or ñ is often the fastest option. The best method is the one that works in the application you are using; no single shortcut behaves identically in every Windows program.

Frequently Asked Questions

What is the Alt code for lowercase ñ?

The common Windows Alt code is Alt + 164. Alt + 0241 is another commonly used code.

What is the Alt code for uppercase Ñ?

The common Windows Alt code is Alt + 165. You can also try Alt + 0209.

Can I type Ñ on a laptop without a numeric keypad?

Yes. You can use Windows character tools, an on-screen keyboard, a suitable keyboard layout, or copy the character directly.

How do I type Ñ in Word?

You can use the Windows Alt code with a numeric keypad, insert the character through Word's symbol options, or copy Ñ and paste it into your document.

Can I copy Ñ and ñ into any Windows application?

In most modern applications that support Unicode text, yes. You can copy the actual character and paste it into documents, browsers, messages and many other text fields.
