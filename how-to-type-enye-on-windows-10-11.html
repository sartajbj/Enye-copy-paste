How to Type Enye (Ñ or ñ) on Windows 10 & 11

Need to type the Spanish enye letter on a Windows PC or laptop? You can type uppercase Ñ and lowercase ñ with Alt codes, Character Map, keyboard settings, or an easier copy-and-paste method.

Quick answer: On a Windows keyboard with a numeric keypad, hold Alt and type 164 for ñ, or 165 for Ñ. You can also use Alt + 0241 and Alt + 0209. The numeric keypad is required for traditional Alt-code entry.

Windows Alt Codes for Ñ and ñ

The fastest traditional method on Windows is the Alt code. It is useful when you need the enye character while writing in Word, Notepad, a browser, email, or another Windows application.

ñ Lowercase Enye

Alt + 164
Alt + 0241

Ñ Uppercase Enye

Alt + 165
Alt + 0209

How to type lowercase ñ with Alt + 164

  1. Place the cursor where you want the letter.
  2. Make sure Num Lock is enabled.
  3. Hold the Alt key.
  4. Type 164 on the numeric keypad.
  5. Release Alt. The character ñ should appear.

How to type uppercase Ñ with Alt + 165

  1. Place the cursor in your document or text field.
  2. Turn on Num Lock.
  3. Hold Alt.
  4. Type 165 on the numeric keypad.
  5. Release Alt to insert Ñ.

What If Your Laptop Has No Numeric Keypad?

This is one of the most common problems with Windows laptops. Many compact keyboards do not have a dedicated numeric keypad, so the traditional Alt + 164 or Alt + 165 method may not work.

In that situation, you can use Windows Character Map, enable a suitable keyboard layout, or use the quick copy method when you only need Ñ or ñ occasionally.

Method 1: Use Windows Character Map

  1. Press the Windows key.
  2. Search for Character Map.
  3. Open the Character Map application.
  4. Find ñ or Ñ.
  5. Select the character and click Select.
  6. Click Copy.
  7. Paste it wherever you need it with Ctrl + V.
Tip: Character Map is especially useful on laptops without a physical numeric keypad because it does not depend on Alt-code entry.

Method 2: Copy Ñ or ñ instantly

If you only need the character once, there is no reason to change your Windows keyboard settings. You can simply copy the exact character and paste it into your document.

Use a Spanish Keyboard Layout on Windows

If you frequently type Spanish, changing your Windows keyboard layout can be more practical than repeatedly using Alt codes.

Windows allows you to add another keyboard language through its language settings. After adding a Spanish keyboard, you can switch between layouts using the Windows language controls.

When should you use a Spanish keyboard?

  • You regularly write Spanish text.
  • You frequently need accented characters.
  • You want a keyboard layout designed for Spanish typing.
  • You do not want to depend on numeric Alt codes.

If you only occasionally need Ñ, Character Map or copy and paste is usually quicker.

Ñ vs ñ: Which One Do You Need?

The uppercase and lowercase forms are different characters, so make sure you select the correct one.

Ñ Capital Enye

Used at the beginning of a sentence or in uppercase words and names.

ñ Small Enye

Used in normal lowercase Spanish and other words that contain the letter.

Common Windows Problems When Typing Ñ

Alt code does nothing

Check that you are using the numeric keypad rather than the number row above the letters. Also make sure Num Lock is enabled.

The laptop has no NumPad

Use Character Map, a compatible keyboard layout, or the Enye Copy Paste tool instead of relying on traditional Alt codes.

I typed the wrong character

Remember that Alt + 164 produces lowercase ñ, while Alt + 165 produces uppercase Ñ.

Can I type Ñ in Microsoft Word?

Yes. Windows Alt codes, Character Map, keyboard layouts, and copy-and-paste methods can all be used in Microsoft Word.

Ñ and ñ Unicode Codes

Unicode gives each character a consistent code point that applications can use to represent the character correctly.

  • Lowercase ñ: U+00F1
  • Uppercase Ñ: U+00D1

Unicode is particularly useful when working with HTML, programming, databases, or text that needs reliable character encoding.
